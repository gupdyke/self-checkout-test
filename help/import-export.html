Import / Export

Custom Routes, Hidden Routes and Saved Sessions are saved on this device only. Export saves them to files; Import loads those files on any device running Self Checkout.

Export

In Settings , tap Export. The file is named like self-checkout-routes-2026-10-16.json and holds both your custom and hidden routes. The web app downloads it; the Android app opens the device's share sheet so you can save it or send it to yourself.

Import

Tap Import and pick such a file. It checks every route first. Import adds to the routes you already have and skips any you've already saved, so importing the same file twice is harmless.

Saved Sessions

Export also saves your Saved Sessions, to a second file named like self-checkout-sessions-2026-10-20.json. Import takes either file, or both at once, and tells them apart. Sessions you already have aren't added twice.

Why bother?

Routes and sessions live in your device's own storage. Uninstalling the app, clearing site data or buying a new device erases them. The web app, a Home Screen copy and the Android app also keep separate sets.

Examples

  • New device: export on the old one, send yourself the file, import on the new one.
  • Web to Android: export from the web app, import in the Android app, and both have the same routes.
  • Backup: export after you've set up your routes and keep the file somewhere safe.
