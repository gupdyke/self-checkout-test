Custom Routes

Many outs offer multiple finishing routes by default. Custom Routes lets you see only the ones you want. Save one for any score that can be finished in two or three darts.

Adding one from Settings

  1. Tap , then Custom Routes, then Add custom route.
  2. Enter the finishing score between 2 and 170; a bogey number (169, 168, 166, etc) is not allowed in the list.
  3. Choose one of the suggested routes, or tap Make my own and enter it one dart at a time, pressing Enter after each.

The pencil edits a saved route. The trash can deletes it. Clear all removes them all (it asks first).

Adding one from the main screen

Press and hold a route in Checkouts or Set up and tap Add to Custom Routes. Press and hold a ★ route and tap Remove from Custom Routes to delete it.

What you'll see

On a score with a custom route, Checkouts shows only yours, marked with a ★. Tap Show all to see the others too, and Show custom only to hide them again.

A custom route isn't shown when you don't have enough darts left to finish it. Set up isn't affected.

Making your own: the rules

  • A number that could be more than one bed counts as the single, then the Treble, then the Double: 18 is S18, 36 is T12, 32 is D16. The last dart is always the Double (36 to finish is D18, 50 is the Bull). In other words, a set-up containing T6 or D10 prior to the finishing Double can't be saved.
  • Mistakes are caught as you go: "Only 52 left.", "That leaves 1.", "The last dart has to be a Double.", and on saving, "That route is already saved for 122."

Custom Set up rows

A Set up row can be added the same way. Above 170 and on bogey numbers, Set up rows can't be hidden or added to Custom Routes. It shows instead of the others, marked with a ★, the next time you're on that score with the same number of darts left. Tap Show all to see the others again. Amber rows are still displayed so they can be avoided.

When Set up is visible beneath Checkouts, you can add as many Custom Routes as you like. Only the Custom Routes show, each with a ★. Tap Show hidden Set up routes to see the other rows, and Hide hidden Set up routes to hide them again. A Custom Route can't be hidden.

Where they're kept

On this device only. The web app, a Home Screen copy and the Android app each keep their own. Clearing site data, uninstalling or getting a new device loses them unless you exported them: see Import / Export.
