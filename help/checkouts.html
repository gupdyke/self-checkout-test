Checkouts

The routes that give you the best chance to finish the game as quickly as possible. Use it when your opponent is on a makeable finish.

What the list shows

  • Only routes you can finish with the darts you have left: with 1 dart it's the Double you need; if two darts can do it, no 3-dart routes.
  • Along with the hand-picked routes there's one to each of D20, D18 and D16, so you can find your favorite Double (unless it's checked in Doubles to Avoid).
100, 3 dartsCheckout60, 40 (T20, D20)

Arrows

An arrow shows what a dart leaves. Beneath Checkouts, a Set up row like 60 (T20) → 62 means: hit T20 for 60, and you're left on 62. When there's no checkout, and above 170, each Treble shows both outcomes, Treble → leave / Single → leave (T20 → 120 / S20 → 160), because a dart aimed at the Treble often lands in the Single.

Checkouts and Set up together

On some scores, going for the win and setting up your next throw call for different darts. There, Checkouts and Set up are both on the screen. On every other score you only see Checkouts. See Set up.

With two darts on 104, the only way out is a Treble then the Bull. If going the Bull route is not necessary, Set up provides you with alternatives.

The underlined Checkouts

With 3 darts on 119, 122, 123, 125, 126, 128, 129, 132 or 135, Checkouts is underlined. Tap it to see why its routes don't start on T20.

On 122, a dart at the T20 that lands in the Single leaves 102, which has no 2-dart finish. The routes shown start on T18, whose Single leaves a 2-dart finish, so a miss costs you nothing.

Bull finishes

Routes that finish on the Bull are only shown under Checkouts. With 3 darts, 50 shows S18/D16 or S10/D20 instead; on your last dart it shows D25, with Set up below it for the turn after.
